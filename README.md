# Training-Module-Data
Data from training modules put out for TRANSCEND

Fantastic Graph Types.Rmd -> R-code for Fantastic Graph Types and How To Make Them (R Edition)

Simulate data 2026.R -> R-code for Easy Simulation for Science and Statistics

Logistic Regression vs. Survival Analysis.R -> R-code for Logistic Regression vs. Survival Analysis
LvS_dataset.csv -> dataset for Logistic Regression vs. Survival Analysis

Managing Missing Data Datasets.R -> R-code for creation of full dataset and small dataset
Managing Missing Data Demo.R -> R-code for analysis of the full and missing datasets
brain_miss_full.csv -> full mock dataset for the analyses in Managing Missing Data
brain_miss_MCAR.csv -> MCAR mock dataset for the analyses in Managing Missing Data
brain_miss_MAR.csv -> MAR mock dataset for the analyses in Managing Missing Data
brain_miss_MNAR.csv -> MNAR mock dataset for the analyses in Managing Missing Data
